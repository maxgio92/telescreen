## telescreen install

enroll the stack, or one component (minitrue, speakwrite, thinkpol)

```
telescreen install [component]... [flags]
```

### Options

```
      --dry-run   print what install would write, without writing
      --force     overwrite installed skills the user may have edited
  -h, --help      help for install
```
